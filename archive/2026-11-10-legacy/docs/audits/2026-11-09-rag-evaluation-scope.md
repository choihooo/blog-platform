# 이력서 평가 범위 제외

2026-11-09 사용자 요청으로 평가 fixture에서 `/resume`을 정답으로 요구하는 네 항목만 제외했다. 페이지
제거, 경력 데이터 삭제, 실제 RAG 응답·검색 동작 변경은 하지 않았다.

- 긍정: p2 `개발 경험`, p3 `아이겐 코리아 경력` 제외. 20개 → 18개.
- Calibration: c1 `프론트엔드 경력`, c2 `최호 소개` 제외. 10개 → 8개.
- 부정 10개·후속 5개·주입 3개는 유지. 총 48개 → 44개.
- 신규 v2 12문항에는 이력서 정답 항목이 없어 그대로 유지.

기존 API를 다시 호출하지 않고 2026-11-09 raw 검색 원본 결과를 새 범위로만 재집계하면, 정답 출처
포함은 **16/18 (88.9%)**, 부정 오탐은 **0/10**이다. 이는 새 실험 결과가 아니라 사용자가 정한 범위
변경에 따른 사후 재집계다. 원본 17/20 (85%) 보고서는 수정하지 않았다.

새 범위에서도 남은 raw 검색 실패는 `대표 프로젝트`, `거부기린 사용자 성과` 두 항목이다. 90% 기준은
유지하며 아직 미달이다. cutoff를 다시 조정하거나 실패 항목의 정답을 바꾸지 않았다.

검증: JSON 파싱, 그룹별 개수, `/resume` 정답 잔존 여부, contextFrom 참조, 원본 결과 재집계,
Prettier와 diff 확인. 평가 데이터·문서만 바꿔 앱 테스트·빌드·SEO 검사는 생략했다.
