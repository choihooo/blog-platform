# 채팅 답변 가독성 개선

2026-09-06. 기존 Hozui와 기본 Kanana 모델을 유지하고 출력 구조를 변경했다. 공개 배포는 수행하지
않았다.

## 이력서

- 개발 경험·활동·기술 스택·수상은 공개 이력서 구조화 데이터로 답한다.
- 활동명과 기간은 동일 원본 항목에서 가져온다. 날짜가 없는 활동에 다른 날짜를 추정해 붙이지 않는다.
- 경력과 프로젝트 성과도 섹션 제목·문단·목록을 구분한다.
- 일반 텍스트에서 임의의 쉼표나 날짜를 분해해 사실 관계를 재구성하지 않는다.

## 블로그

- 모델이 만드는 설명과 원본 제목/링크를 별도 상태로 관리한다.
- 기본 두 개의 글을 번호 목록으로 표시한다. 제목을 클릭하면 원문을 새 탭에서 연다.
- 설명은 별도 문단에 스트리밍하며 글 간 여백은 20px이다.
- 블로그 답변에는 중복 참고 자료 목록과 긴 발췌를 표시하지 않는다.
- 그 외 답변의 출처는 접힌 목록으로 유지하고 URL별 중복을 제거한다.
- 원문 제목은 변경하지 않으며 텍스트는 React가 이스케이프한다. 생성 HTML을 실행하지 않는다.
- 생성 중지/실패 시 빈 설명이 무한 로딩 문구로 남지 않도록 안내한다.

## 검증 및 한계

- 전체 Vitest 91개 통과, TypeScript 검사 및 lint 통과.
- SSR 테스트로 실제 제목 링크, h3/ul/li/ol/p 구조, 원문 날짜 보존, HTML 이스케이프 확인.
- Next/Vite의 JSX 보존 설정 차이 때문에 Vitest에 자동 JSX 변환을 명시했다.
- 이번 변경에서는 브라우저 시각 검수 및 프로덕션 빌드를 실행하지 않았다.
- 모델 자체의 요약 정확도는 별개이며, 네이버 모델 실험 정책을 서비스에 연결한 변경이 아니다.
