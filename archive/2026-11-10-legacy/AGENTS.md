# 블로그 플랫폼

단일 운영자가 기술 글을 작성·미리보기·발행하고, 독자는 공개 포트폴리오와 블로그에서 글과 프로젝트를
탐색하는 플랫폼이다. 편집·발행·검색·SEO를 연결하고, 여러 앱이 쓰는 로직은 공유 패키지로 관리한다.

## 주요 구성

- `apps/blog`: 캐릭터 스크롤 홈 기반 공개 포트폴리오·블로그
- `apps/cms`: 비공개 운영자용 콘텐츠 편집·발행 CMS
- `apps/rag-worker`: Cloudflare Worker 기반 검색·RAG API
- `packages/*`: 여러 앱에서 공유하는 TypeScript 패키지
- `scripts/`: 개발·콘텐츠 마이그레이션·운영 스크립트
- `specs/`: 기능 명세와 앱·패키지 사이의 계약
- `docs/`: 설계·운영 runbook·감사 기록

수정할 경로의 하위 `AGENTS.md`를 함께 읽는다. 작업 절차·검증과 주제별 지침은
[개발 작업 가이드](docs/development-guide.md)에서 필요한 항목을 확인한다.
