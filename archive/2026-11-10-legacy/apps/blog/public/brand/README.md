# 사이트 공유 이미지와 아이콘

- `hozorica-card-v2.webp`: 1200×630 기본 OG/Twitter 카드. 현재 사이트의 아이보리·남색 톤으로
  Hozorica 워드마크와 흰색 옷 캐릭터만 배치한다. 승인 프로필과 현재 인사 장면을 레퍼런스로 내장
  image_gen으로 생성했으며, 주소·인사말·장식은 사용자의 최종 요청에 따라 제거했다.
- `app/icon.png` 512×512, `app/apple-icon.png` 180×180, `app/favicon.ico` 32×32는 승인된
  `hozorica/brand/profile.png`에서 변환했다. Next.js의 파일 기반 아이콘 메타데이터를 사용해 PNG의
  내용 해시와 실제 크기를 반영한다. 루트 레이아웃에서 중복된 고정 아이콘 URL을 지정하지 않는다.
- 기본 공유 카드만 새 파일명으로 연결한다. 글에 썸네일이 있으면 해당 이미지를 유지하고, 썸네일이
  없는 글의 `/og/[slug]` 생성 경로도 유지한다.
- 이전 `hozorica-card.webp`는 기존 공유 링크를 위해 남겨두지만 새 메타데이터에서는 사용하지 않는다.
