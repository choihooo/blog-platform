# 둥근 블로그 스타일 시안

`/experiments/blog-rounded`에서 실제 발행 글·썸네일을 새 디자인으로 비교한다. 기존 `/blog`와 상세는
바꾸지 않는다. 시안 목록·상세는 noindex이며 canonical은 기존 블로그 주소다. 셸은 이 경로에서만 기존
검색 헤더를 숨기고 MainHeader를 한 번 표시한다.

현재 브랜드의 아이보리·남색·블루와 SUIT를 상속한다. 카드 24px, 검색창 16px, 상세 문서 28px의
라운드를 사용하며 CSS와 테마 변수는 `.rounded-blog` 안에 제한한다. 이미지 비율은 원본 썸네일의
16:9를 유지한다.

실제 공개 글을 서버에서 읽고 카드에 필요한 요약 필드만 클라이언트로 넘긴다. 카테고리(부모/하위),
제목·요약·태그 검색, 카드 보기(데스크톱 2열·모바일 1열), 자동 추가 로딩, 빈 결과 초기화를 제공한다.
검색은 로컬 요약 필터 시안이며 본문 전체 검색이나 서버 검색 API를 대체하지 않는다. 상세는 기존 body
renderer를 재사용하고 실제 본문, 작성자, 썸네일, 읽기 시간과 목차를 보여준다. 데이터 저장·발행
작업은 없다.

상세 하단은 발행일순 이전(더 오래된 글)·다음(더 최신 글) 이동과 현재 글 주변의 글 목록 5개를
제공한다. 현재 글은 읽는 중으로 강조하며 가장자리에서는 목록 창을 조정한다. 이전/다음 글이 없으면
링크를 만들지 않는다. 모든 이동은 예시 경로를 유지한다.

목록은 처음 8개를 보여주고 끝에서 600px 이내에 접근하면 다음 8개의 썸네일을 준비한다. 준비 중에는
카드 스켈레톤을 보여주며 이미지 오류나 지연이 있어도 1.5초 후 글을 표시한다. 이는 이미 받은 공개
요약 데이터를 점진적으로 표시하는 방식이며 서버 페이지네이션은 아니다. TanStack Virtual의 window
virtualizer가 실제 행 높이를 측정하고 화면 주변 2개 행만 추가 렌더링한다. 검색·카테고리 변경은 첫
묶음으로 초기화하며 모바일 전환 때는 행을 다시 묶고 측정한다. 감소된 모션에서는 스켈레톤의 펄스
효과를 끈다.
