## 화면 폭 바꾸기

넓은 화면에서 한 줄이던 제목도 작은 화면에서는 여러 줄이 됩니다. 날짜가 제목을 밀어내거나 코드가 페이지 전체를 넓히지 않는지 확인합니다.

## 키보드로 이동하기

Tab으로 링크를 선택하고 Enter로 이동해 봅니다. 지금 선택한 위치가 보이는지, 뒤로 돌아왔을 때 목록을 계속 읽을 수 있는지 살펴봅니다.

기본 요소가 제공하는 동작을 유지하면 별도 설명 없이도 사용할 수 있는 부분이 많아집니다.
