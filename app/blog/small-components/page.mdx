## 먼저 반복을 살펴보기

모양이 비슷하다는 이유만으로 컴포넌트를 나누기보다, 어떤 정보와 동작이 함께 바뀌는지 먼저 살펴봅니다.

한 화면 안에서 반복되는 제목과 설명을 묶으면 읽는 사람도 코드를 고치는 사람도 관계를 찾기 쉽습니다.

## 이름으로 역할 드러내기

컴포넌트 이름은 내부 구현보다 화면에서 맡는 역할을 설명할 때 이해하기 쉽습니다.

```tsx
function PostSummary({ title, description }) {
  return <article><h2>{title}</h2><p>{description}</p></article>;
}
```

작게 나누는 것 자체보다, 다음 변경을 어디에서 시작할지 알 수 있는 구조를 목표로 합니다.
