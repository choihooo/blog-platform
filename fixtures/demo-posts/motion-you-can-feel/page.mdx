}

## 같은 거리, 다른 움직임

세 공은 같은 시간 동안 같은 거리를 이동합니다. 다른 것은 출발하고 멈출 때의 속도 변화입니다.

<EasingDemo />

<DemoCaption>재생을 누르면 공이 이동합니다. 다시 누르면 반대 방향으로 돌아옵니다.</DemoCaption>

| 곡선 | 관찰할 부분 |
| --- | --- |
| linear | 처음부터 끝까지 일정한 속도로 이동합니다. |
| ease-out | 빠르게 출발하고 끝에서 천천히 멈춥니다. |
| ease-in-out | 천천히 출발해 중간에 빨라지고 다시 감속합니다. |

어떤 곡선이든 정답이 되기보다, 화면에서 설명하려는 변화와 어울리는지를 확인하는 편이 좋겠습니다.
