# 프로젝트 성과 질문 우선순위 검증 — 2026-11-09

성과·사용자 수 질문은 실제 프로젝트 식별자 또는 임계값을 넘은 현재 벡터 근거가 있을 때 프로젝트
페이지를 우선한다. 명시적인 글·회고·후기 질문은 기존 글 우선순위를 유지한다. 일반적인 비교·검증
단어만으로 프로젝트를 식별하지 않는다. 사용자 수 질문의 발췌는 명 단위를 우선한다.

- 실제 Gemini 검색 holdout: 정답 출처 17/17, 부정 오탐 0/10, 전체 27개 HTTP 200.
- 실제 변형 질문 6/6 통과: 성과·사용자 수·넥사크로 성과, 글·회고 의도, 미등록 프로젝트.
- 실제 생성 답변: 거부기린 프로젝트가 첫 출처이며 43명·약 1,300시간을 답변에 포함.
- 단위 테스트: 별칭, 수치 단위, 약한·stale 후보, 일반 비교 단어, 이름 없는 의미 검색 회귀 포함.
- 전체 `pnpm test`, `pnpm lint`, `pnpm typecheck`, `pnpm build` 통과 (병합 전 기준).

검색 임계값 0.7과 corpus 입력·ID는 변경하지 않았다. 580개 corpus의 revision과 contentRevision을 변경
전후 dry-run으로 비교하며 원격 쓰기·재임베딩·배포는 수행하지 않는다. 실제 결과는 동명
`-results.json`에 보관한다. 이전 보고서는 당시 결과로 유지한다.

공개 페이지·메타데이터·본문 렌더링을 수정하지 않아 이번 변경의 SEO 검사는 생략한다. CMS 발행·비공개
전환과 실제 운영 롤백 검증은 별도 운영 전환 단계로 남아 있다.

## main 구조 통합 검증

`main`의 모듈 이동에 맞춰 공통 검색·추출 코드는 `packages/core`, 채팅은
`apps/blog/features/chat`에 통합했다. 삭제된 editor 패키지는 복원하지 않았다. 초기 HTML의 채팅
버튼을 유지하도록 로컬 컴포넌트는 즉시 렌더링하고 모델 로드는 사용자 열기 이후로 유지한다.

- 병합본 `pnpm test`: 727개 통과, CMS 기존 1개 건너뜀.
- 병합본 `pnpm lint`, `pnpm typecheck`, `pnpm build` 통과. Worker 빌드는 dry-run이다.
- Core·Blog `format:check`, Worker `typegen` 통과.
- 기존 corpus 보존 snapshot과 패키지 경계 검사 통과. 운영 설정 변경·배포·원격 쓰기 없음.
- 실제 API 평가 수치는 병합 전 결과이며 병합 후 원격 API 평가는 다시 실행하지 않았다.
