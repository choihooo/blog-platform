마우스를 내려놓고 링크를 따라가 보기

키보드 초점과 기본 링크의 동작을 살펴보며 작은 인터페이스의 사용감을 생각합니다.

2026년 10월 29일최호예시 글

완성한 화면을 확인할 때 가끔 마우스를 내려놓고 Tab 키만 눌러봅니다. 눈으로 보면 분명했던 이동 경로가 키보드로도 자연스럽게 이어지는지 확인하기 위해서입니다.

지금 선택한 위치

링크에 초점이 갔을 때는 현재 위치가 보여야 합니다. 마우스를 올렸을 때의 배경색과 키보드로 이동했을 때의 초점 테두리는 서로 다른 상황에서 같은 역할을 합니다.

a:focus-visible {
  outline: 2px solid currentColor;
  outline-offset: 4px;
  border-radius: 2px;
}

초점의 모양은 화면과 어울리게 바꿀 수 있지만, 위치를 알 수 있는 단서는 남겨두어야 합니다.

링크가 이미 해주는 일

다른 페이지로 이동할 때는 링크를 사용합니다. 기본 요소를 선택하면 브라우저가 제공하는 여러 동작을 함께 사용할 수 있습니다.

동작확인할 내용
Tab으로 이동링크가 순서대로 선택되는가
Enter로 실행선택한 페이지로 이동하는가
새 탭으로 열기브라우저의 기본 메뉴로 가능한가
뒤로 가기읽던 목록으로 돌아갈 수 있는가

익숙한 동작이 예상대로 이어지는 것도 사용감을 만드는 중요한 부분입니다.

작은 확인을 습관으로

화면이 작을 때, 제목이 길 때, 키보드로만 이동할 때를 한 번씩 확인해 봅니다. 각각의 상황이 특별한 기능을 요구하지는 않습니다.

처음부터 기본 요소의 동작을 살려두면 나중에 덧붙여야 할 처리도 줄어듭니다.
