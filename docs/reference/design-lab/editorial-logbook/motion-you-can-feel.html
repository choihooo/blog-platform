눌러 보고 비교하는 작은 애니메이션

버튼의 눌림, 요소의 등장 순서, 같은 속도의 다른 움직임을 본문 안에서 직접 비교해 봅니다.

2026년 11월 8일최호예시 글

애니메이션은 설명을 읽는 것보다 한 번 눌러볼 때 차이가 더 잘 느껴집니다. 이 글에는 같은 동작을 서로 다른 방식으로 표현한 예제를 모았습니다.

손끝에 반응하는 버튼

아래 두 버튼을 눌러보세요. 한쪽은 크기가 그대로이고, 다른 쪽은 누르는 동안 조금 작아집니다. 작은 변화지만 입력을 받았다는 감각이 달라집니다.

기본 버튼
눌림 효과

버튼을 누르는 동안의 반응을 비교해 보세요.

이 효과는 CSS의 :active와 transform으로 만들 수 있습니다. 아래는 같은 원리를 표현한 짧은 예시입니다.

button {
  transition: transform 150ms ease-out;
}

button:active {
  transform: scale(0.97);
}

먼저 보여주는 내용

제목과 설명, 버튼이 순서대로 나타날 때 시선도 그 순서를 따라갑니다. 아래 예제의 재생 버튼을 눌러 두 가지 등장 순서를 비교할 수 있습니다.

먼저 전하고 싶은 이야기

제목 다음에는 짧은 설명이 이어집니다.

이어서 읽기

각 패널 오른쪽 위의 버튼으로 다시 재생할 수 있습니다.

여기서 긴 지연 시간은 차이를 관찰하기 위한 설정입니다. 자주 쓰는 화면에 그대로 적용하기보다는, 독자가 무엇을 먼저 이해해야 하는지 생각하는 출발점으로 볼 수 있습니다.

같은 거리, 다른 움직임

세 공은 같은 시간 동안 같은 거리를 이동합니다. 다른 것은 출발하고 멈출 때의 속도 변화입니다.

linear
ease-out
ease-in-out

재생을 누르면 공이 이동합니다. 다시 누르면 반대 방향으로 돌아옵니다.

곡선관찰할 부분
linear처음부터 끝까지 일정한 속도로 이동합니다.
ease-out빠르게 출발하고 끝에서 천천히 멈춥니다.
ease-in-out천천히 출발해 중간에 빨라지고 다시 감속합니다.

어떤 곡선이든 정답이 되기보다, 화면에서 설명하려는 변화와 어울리는지를 확인하는 편이 좋겠습니다.
