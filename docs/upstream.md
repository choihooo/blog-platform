## 가져온 것

Next.js·MDX·Tailwind 설정과 잠금 파일, 메인·글 레이아웃, 전역 스타일, 글 목록 수집기, MDX 공통 부품을 가져왔습니다. 애니메이션과 캐싱 데모는 원본 코드를 유지한 채 `components/demos/animation`, `components/demos/cache-components`로 이동했습니다. 파일 내부의 출처·라이선스 주석은 보존했습니다.

## 가져오지 않은 것

원저자의 글 4편, 글 이미지와 영상, 개인 favicon과 공유 이미지, 기본 템플릿 이미지, 원본 `.git/`와 에이전트 설정은 가져오지 않았습니다. Giscus 컴포넌트와 의존성도 제거해 원저자의 Discussion에 연결되지 않게 했습니다.

## 최소 변경

- 이름·제목·소개·GitHub 링크를 현재 운영자 정보로 교체.
- 글이 0개인 경우 작은 텍스트 안내.
- 모바일 날짜를 제목 아래로 배치.
- 준비 중인 사이트에 `noindex, nofollow` 적용.
- TypeScript·ESLint가 아카이브·HTML 시안·이전 앱 생성물을 읽지 않도록 제외.
- 기존 저장소 이력·아카이브·HTML 시안 보존.
- 글이 0개여도 MDX 동적 import가 빌드되도록 `_template` 작성용 폴더를 두고, `_` 폴더를 목록에서 제외. Next.js의 private folder이므로 공개 라우트는 생성되지 않음.

## 데모 사용 시 구분

흐름도의 시간은 시뮬레이션 값이며 실제 네트워크 측정값이 아닙니다. 모달·툴팁을 실제 서비스 UI로 쓸 때는 초점 관리·키보드 동작·타이머 해제를 별도로 검증합니다.

디자인 자동 검사에서 원본 모달 데모의 바운스 이징을 경고했습니다. 과한 모션을 비교 설명하기 위한 원본 예제이므로 유지했으며 홈 화면에는 적용되지 않습니다.
