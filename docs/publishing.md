# 글 작성과 발행

글은 MDX 파일로 작성하고 Git 변경으로 발행합니다. 웹 편집기·DB는 사용하지 않습니다.

1. `app/blog/_template/page.mdx`를 `app/blog/_drafts/<slug>/page.mdx`로 복사해 작성합니다. `_drafts` 아래는 라우트가 생성되지 않습니다. 초안은 운영 사이트에서 미리볼 수 없습니다.
2. 발행용 slug는 영문 소문자·숫자·하이픈만 사용합니다. 제목·요약은 비어 있지 않은 문자열, 날짜는 실제 달력의 `YYYY-MM-DD`여야 합니다. `demo: true`인 글은 발행되지 않도록 빌드가 실패합니다.
3. 로컬에서 화면을 볼 때는 작업 브랜치에서 글을 `app/blog/<slug>/page.mdx`로 옮깁니다. 공개 경로로 옮긴 글은 미리보기 배포 URL에서도 접근 가능하므로 공개 가능한 내용만 둡니다.
4. `pnpm test`, `pnpm lint`, `pnpm exec tsc --noEmit`, `pnpm build`를 통과시킵니다. `pnpm dev`에서 제목·목차·코드 복사·모바일 줄바꿈을 확인합니다.
5. 작업 브랜치를 GitHub에 반영해 미리보기 배포를 확인한 뒤 Production 브랜치에 반영합니다. 이후 글을 수정할 때도 같은 순서를 사용합니다.

MDX는 빌드 시 실행되는 코드이므로 신뢰하는 운영자만 작성합니다. 출처와 실제 경험을 확인한 글만 발행합니다. 실제 글이 아직 없으면 빈 목록을 그대로 운영할 수 있습니다.

비공개 작성 템플릿 `app/blog/_template/page.mdx`를 복사해 실제 글을 작성합니다. `demo: true`인 글은 발행 검증에서 거부됩니다.
