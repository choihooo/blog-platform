# 글별 OG 이미지

글의 `post.title`과 `post.description`을 공통 코드 템플릿에 넣어 1200×630 PNG로 생성합니다. OG와 Twitter가 같은 이미지를 사용합니다. 홈 공유 이미지는 기존 이미지를 유지합니다.

- 디자인: `lib/og-image.tsx`
- 분기·색상: `lib/og-theme.mjs` (현재 `2026-q4`)
- 이미지 주소: `/og/<slug>?v=2026-q4`
- 글 목록을 기준으로 빌드 시 생성하며 비공개·알 수 없는 주소는 404입니다.
- 2026 Q4는 차콜 바탕과 흰 제목을 사용합니다. SUIT Bold 700, 제목 최대 3줄·요약 최대 2줄이며 긴 글은 이미지에서만 말줄임 처리합니다.
- 텍스트는 좌우 72px 여백을 둔 전체 1056px 영역에 배치합니다. 제목은 길이에 따라 72·62·50px, 요약은 28px이며 주소·분기는 아래 양 끝에 표시합니다. 큰 ‘호’와 상단 블로그 이름은 표시하지 않습니다.

분기마다 템플릿을 수정하고 `edition`과 `label`을 함께 바꾼 뒤 재배포합니다. 날짜가 바뀌었다고 디자인이 자동으로 바뀌지는 않습니다. 공유 서비스의 기존 미리보기 캐시는 서비스별로 갱신이 필요할 수 있습니다.

OG용 정적 폰트는 기존 SUIT Variable에서 변환한 동일 라이선스의 에셋입니다. 재생성: `python3 scripts/generate-og-font.py` (fontTools·brotli 필요).
