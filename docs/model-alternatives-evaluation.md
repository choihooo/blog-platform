# 한국어 브라우저 모델 대안 실험 — 2026-09-06

## 결론

- Qwen3-1.7B Q4_K_M은 현재 Wllama 브라우저 WebGPU 환경에서 로딩·한국어 생성에 성공했다.
- 단순 글 소개는 가능하지만 어색한 한국어, 소개 답변 잘림, 자료 속 악성 지시를 따른 허위 수상 경력
  생성이 확인됐다. 이 설정으로 기존 모델을 즉시 교체하지 않는다.
- 후속 실험: 사용자가 이용 조건에 동의했다고 알린 뒤, NAVER-Cloud-HyperCLOVA-X의 공식 fork가
  연결하는 공개 `naver-ellm` GGUF로 HyperCLOVAX-SEED-Text-Instruct-1.5B 네이티브 비교 9회도
  실행했다. 한국어 소개는 더 간결하고 첫 AI 글 요약은 더 자연스러웠지만, 기술 개념 질문에서는 명확한
  오답이 나왔다. 아래 후속 실험을 참조한다.
- 운영 앱 소스, 모델 기본 URL, 기존 캐시, 배포 환경을 바꾸지 않았다. 실험은 별도 localhost 서버와
  임시 브라우저 탭에서 수행했다.

### 판단 및 기록

두 후보 중 공개 자료에 근거한 짧은 한국어 소개를 추가 실험할 후보로는 네이버를 우선 고려한다. 근거
없는 기술 질문까지 자유롭게 답하게 하는 용도로는 둘 다 현재 설정이 불충분하다. 실제 도입 전에는 질문
범위를 포트폴리오로 제한하고, 근거 없음 응답을 앱에서 확정하며, 제목 복사와 요약을 구분하고,
공격·회귀 질문을 늘려야 한다. 모델 교체나 공개 배포는 수행하지 않았다. 재배포 라이선스 검토도
별도다.

원시 결과 보관 폴더에 `hyperclova-results.json`, `hyperclova-browser-results.json`,
`hyperclova-server.log`를 추가했다. 실험용 네이티브·브라우저 서버와 테스트 탭은 종료하며, 약 1.01GB
모델은 재실험을 위해 임시 폴더에 유지한다. 서비스 소스 및 기존 캐시는 변경하지 않았다.

## 후속: 포트폴리오 전용 응답 규칙 개선 실험

기본 모델을 바꾸지 않고 별도 실험 모듈 `portfolio-policy.mjs`, 테스트 `portfolio-policy.test.mjs`,
실행 스크립트 `refine.mjs`를 원시 결과 보관 폴더에 추가했다. 프로덕션 앱에서는 import하지 않는다.

### 변경 사항

- 일반 지식 질문은 고정 범위 안내로 돌린다. 확인되지 않은 인물·경력 질문은 확인 불가 안내를
  사용한다. 모델의 추측으로 답하지 않는다.
- 프로필 질문은 지정된 이력서 기술 스택 자료를 그대로 인용한다. 모델이 소개 문장으로 재작성하지
  않는다.
- 글 소개는 알려진 주제(React, AI, Next, TypeScript, 캐시)의 제목 일치를 보수적으로 검사한다. React
  검색의 무관한 추천 시스템 글 대신 원래 3위였던 React Router 글이 선택된다.
- 제목·번호·링크는 모델 외부에서 확정한다. 미완성 문장, 제목 반복, 길이 초과, 토큰 제한 종료는 원문
  확인 안내로 대체한다.
- 발췌의 중복 구간과 잘린 끝부분을 줄인다. 단순 마침표 분리가 `v6.4`를 잘라내는 버그가 발견돼
  `Intl.Segmenter('ko')`로 수정하고 회귀 테스트를 추가했다.
- 요약 지시를 짧게 줄이고, 한 문장으로 “이 글은 … 다뤄요.” 형태를 요청한다.

### 한계와 적용 상태

- 4/4는 문장 형식 통과율이며 사실 정확도나 보안 성공률이 아니다. 예를 들어 이슈 트래커 소개는 여전히

  조사한 결론이 아니다.
