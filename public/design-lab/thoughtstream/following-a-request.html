브라우저에서 서버까지, 요청 하나를 따라가 보기

요청과 응답을 움직이는 흐름도로 살펴보고, 처음 보이는 화면과 나중에 채워지는 내용을 구분합니다.

2026년 11월 5일최호예시 글

화면에 데이터가 나타나기까지 여러 단계가 이어집니다. 요청을 보내고, 서버가 처리하고, 응답을 받은 뒤에 화면을 그립니다. 글로 나열하면 단순하지만 실제로는 단계의 순서와 의존 관계가 중요합니다.

요청이 지나가는 자리

아래 그림에서는 브라우저와 서버를 서로 다른 줄에 놓았습니다. 카드가 차례로 켜지고 연결선을 따라 점이 이동하면 다음 단계가 시작됩니다.

요청 보내기브라우저
데이터 조회서버
응답 받기브라우저
화면 표시브라우저

단계가 차례로 강조되는 설명용 시뮬레이션입니다.

시간은 흐름을 설명하기 위해 정한 예시 값이며 실제 성능 측정 결과가 아닙니다.

점이 움직이는 시간과 서버가 데이터를 처리하는 시간은 서로 다른 구간입니다. 느린 화면을 살펴볼 때도 네트워크 이동과 처리, 렌더링을 나누어 생각하면 어떤 부분을 확인해야 할지 정리하기 쉬워집니다.

먼저 보이는 것과 나중에 채워지는 것

상품 이름과 설명은 먼저 보여주고, 사용자마다 달라지는 장바구니나 재고 정보는 나중에 채워지는 화면을 생각해 볼 수 있습니다.

SHOP 장바구니: 3

운동화

가볍고 편안한 데일리 러닝화.

재고 12개 남음

고정된 화면 위에 동적 내용이 채워지는 예시입니다.

장바구니와 재고 자리가 서로 다른 시점에 채워지는 과정을 반복합니다.

위 그림은 그 순서를 표현한 시뮬레이션입니다. 실제 상품 API를 호출하거나 재고를 조회하지는 않습니다.

그림과 함께 남길 설명

움직이는 그림은 순서를 보여주지만, 글의 설명까지 대신하지는 않습니다. 각 단계가 왜 필요한지와 어떤 조건에서 달라지는지는 문장으로 함께 적어두려고 합니다.

움직임을 보지 못하는 환경에서도 같은 내용을 이해할 수 있도록, 핵심 순서는 본문에도 남깁니다.
